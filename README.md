# Full body — трекер тренировок

Веб-приложение для iPhone: запись подходов, цель на тренировку, рекорды, посещаемость.
Данные хранятся только в браузере телефона (localStorage); в репозитории их нет.

- Открыть в Safari → «Поделиться» → «На экран Домой».
- История: вкладка «Данные» → CSV листа «Журнал» или выгрузка из приложения.
- Резервная копия: вкладка «Данные» → «Выгрузить CSV».

Файлы: `logic.js` — расчёты без интерфейса, `app.js` — экраны, `sw.js` — офлайн-кэш
(при выпуске новой версии увеличить `VERSION`).
