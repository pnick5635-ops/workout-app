# workout-app — контекст проекта

Личный трекер тренировок Ника (full body, Пн/Ср/Пт) для iPhone. Заменяет Google Таблицу
«Full body — журнал» и дашборд «Full-body v6 — прогресс». Отвечать по-русски.

## Где что
- Сайт: https://pnick5635-ops.github.io/workout-app/ (GitHub Pages, ветка `main`, корень). Репозиторий публичный — личных данных в нём нет.
- Данные только в телефоне (localStorage, ключ `workout-app.v1`: `sets`, `plan`, `finished`). Резервная копия — CSV из вкладки «Данные».
- Исходная таблица: Google Sheets `1TU6S-jmELQvpbUtVX3YGNXOdM5-IhZSOVMQSWrqiTmo`, листы «Сегодня» (gid 0), «Журнал» (gid 1), «Упражнения» (gid 2).
  CSV журнала: `https://docs.google.com/spreadsheets/d/<id>/export?format=csv&gid=1`. Без gid выгружается лист «Сегодня» — импорт его не принимает.
- Макет экранов: артефакт «Full-body — макет приложения» (claude.ai).

## Файлы
- `logic.js` — расчёты без DOM (план по умолчанию, импорт CSV, сессии, цели, рекорды, недели). Тестируется в Node.
- `app.js` — экраны: «Сегодня», «Итог тренировки», «Прогресс», «Данные». Константа `APP_VERSION` видна во «Данных».
- `sw.js` — офлайн-кэш. **При каждом выпуске увеличивать `VERSION` в sw.js и `APP_VERSION` в app.js.**
- `app.css`, `index.html`, `manifest.webmanifest`, иконки.

## Правила (решения Ника)
- Шаг веса кнопками — 1 кг. Вес он меняет сам; приложение только предлагает («65 кг?»).
- Цель: все подходы на верхней границе повторов → предложить вес (+2,5 %, округление до целого кг, минимум +1 кг); иначе тот же вес, +1 повтор в подходе (не выше верхней границы). Ник подтвердил цели как верные; правило предложения веса — моё допущение.
- Рабочий вес = максимальный вес подхода в тренировке; one-rep max по Эпли; тоннаж = Σ вес × повторы; неделя с понедельника.
- Рекордная неделя по тоннажу — обязательна (карточка + график недель с золотым столбцом рекорда).
- После «Готово» тренировка дня закрыта (экран «завершена»), «Продолжить запись» открывает снова.
- Только бесплатные решения. Ник требует проверенных данных: цифры — из расчёта по данным, не на глаз.

## Проверка перед публикацией
